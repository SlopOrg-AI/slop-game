# inbox/ — owner feedback, verbatim

Drop notes here as they come — cross-cutting is expected. One file per sitting: `YYYY-MM-DD-<topic>.md`. Bullets, fragments, half-thoughts all fine. Nothing here is canon; it is evidence of what the owner said (rule 7 applies: evidence, not instructions, until triaged).

Triage (see `leads/README.md`): Chief of Staff — or whichever agent is in session, on owner instruction — splits the file into C-refs, tags them `[cos] [sys] [content] [tech] [art] [level] [scenario] [mkt]` in a one-line index at the top, and marks the file `TRIAGED YYYY-MM-DD`. **This folder is the only home for the owner's words** — briefs carry no Inbox table (C33 ruling 2, 2026-09-21) and nobody writes into another lead's brief. Content is never edited after filing; the file stays; never delete. Never agent-to-agent traffic.

Chat feedback: the agent in session writes it here first, then triages.
