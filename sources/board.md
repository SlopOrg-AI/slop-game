### World-board logic

The useful distinction is **ecology → livelihood → architecture → clothing**, rather than simply inventing eight costumes.

**Jungle → longhouse / forest paths**  
**Swamp → reeds / canoe / raised ground**  
**Desert → caravan / portable shelter**  
**River → boats / docks / fishing**  
**Village → agriculture / permanent homestead**  
**City → trade / density / specialized crafts**  
**Pilgrim → roads / shrines / temporary camps**

That gives us a coherent world where factions look like they developed *because of where and how they live*, while still leaving room for the shōnen/fantasy exaggeration later.
