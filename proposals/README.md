# proposals/ — non-canon inbox

Anyone (ChatGPT, Codex, local model, owner brainstorm) writes here freely. Nothing here is canon.

- File name: `YYYY-MM-DD-<topic>.md`. Art boards / image sets: `art/YYYY-MM-DD-<topic>/`.
- Header: who produced it, which design doc it targets, what it proposes, what it would supersede.
- Promotion: owner (or an agent the owner directs in-session) logs a D-number in `design/decisions.md` and edits the target doc. Then mark the proposal `PROMOTED D#.#` or `REJECTED` at the top. Never delete.
