# Proposal — world content: River Nomads (worked example + repeatable method)

**Produced by:** Claude (Cowork, acting as art lead), 2026-09-20 · **Targets:** `design/21-world-factions.md` (stub) · **Proposes:** one faction developed in real content depth, plus a repeatable method for the remaining 7 · **Supersedes:** nothing (no D-numbers claimed). Status: `PROPOSED`.

---

## 0. Method — how this was built

Every beat below is extrapolated from a specific row already DECIDED in `01-pillars.md`'s influence table, kept strictly inside that row's `owns` column, and checked against the anti-goals before it's written down. Each beat is tagged with its source so the reasoning stays visible — this is the "inspiration manager" mentality applied directly to content, not a separate checklist to run afterward. Where a beat would need to borrow from another row's owned territory, it's flagged as an open question instead of taken.

Starting faction: **River Nomads / River People** — `sources/board.md` built the base culture (ecology → livelihood → architecture → clothing); the `01-pillars.md` Noir·caballero/frontier row separately flags this as the faction to develop first ("per-region flavor, River Nomads first"). Same faction, two names in two documents — reconciling that is an open question below, not decided here.

## 1. Base culture (already established, `sources/board.md`)

Long narrow boats, docks instead of roads, fishing nets, poles/paddles, stilt buildings, river markets, settlements stretched linearly along banks. Ecology → livelihood → architecture → clothing: the river *is* the street.

## 2. New content, extrapolated

**Anachronism marker** *(Pillar 5 "living, anachronistic world"; Cassette cyber-funk row — owns "props, media, signal culture")*
River Nomads run the world's informal information network: colored lantern codes, drum-signals between boats, and salvaged pre-collapse radio sets lashed to a boat's prow for river-to-river trade chatter. This is their tech-ceiling expression — analog signal culture on the water. Kept inside Cassette cyber-funk's scope (props/media/signal), not touching HUD or palette, which that row explicitly doesn't own.

**A mortal legend, not a god** *(D5.13 marks/legacy — "remembered facts decaying to a legend tier"; Malazan Book of the Fallen, D5.21 — ascension through remembered deeds, explicitly NOT the marks mechanic itself or world-scale FUTURE flavor)*
A real river-pilot who reopened a flooded channel after a regional catastrophe, at personal cost, and is gone now. Her name is invoked as a landmark on that stretch of river — a *mark*, per the already-decided system, not a deity. This is the first concrete instance of D5.13's marks/legacy mechanic and shows the Malazan-ascension flavor at the scale D5.21 actually licensed: mortal, remembered, not divine.

**Political scale — crews, not a kingdom** *(ASOIAF row — "20 good men scale logic, named-but-mortal, institutions with agendas"; The Black Company, D5.20 — grunt's-eye view of war, mercenary company as narrative unit)*
No monarchy. Boat-crews answer to a named, fallible **channel-master**. Toll disputes between flotillas play out at Black Company's scale — a few dozen boat-hands with a stake in it, not armies — and read through ASOIAF's "named-but-mortal, institutions with agendas" rather than epic-fantasy politics.

**Tradeable good: route-knowledge, not cargo** *(Pillar 8 "Knowledge is power"; Witcher row — "knowledge as trade"; ties directly to the decided knowledge-tier system, D5.10)*
The faction's actual economic identity is selling **witnessed facts** — safe channels, flood timing, which crossings are still passable after a local catastrophe — using the same witnessed → identified → studied tiers already decided for the information system generally. This isn't a new mechanic; it's the existing one given its first faction-level application.

**Visual anchor** *(Ukiyo-e, D5.16 — atmospheric overworld backdrop; Paper Mario / paper-doll, D5.19 — silhouette-first construction; the paper-cutout flat-color rule, inspiration-index §2C)*
Low boats and dock silhouettes suit the flat-color, silhouette-first paper-doll language directly. River mist and travel atmosphere reuse the same Hiroshige Tōkaidō reference already cited for D5.16 — this faction's visual world doesn't need a new reference, it needs the existing one pointed at water instead of roads.

## 3. What this deliberately doesn't touch

- No combat/ability content — the schema drift flagged earlier (`data/README.md` citing D5.25–D5.36, unlogged) makes that the wrong thing to build on right now.
- No new influence-table rows — everything above cites existing DECIDED rows; nothing here needed a new one.
- No world-era or global claims — stays inside "per-region flavor," per the Noir row's own scope.

## 4. Repeatable method for the remaining 7 factions

For each of Jungle/Deep Forest, Swamp/Wetland, Desert Nomads, Desert Villagers/Oasis, City Dwellers, Pilgrims, Agricultural Villagers — same five beats, same discipline:
1. Anachronism marker — which owned row's tech/props territory expresses this region's era?
2. A mortal mark (D5.13) — one remembered deed, not a deity, scaled per D5.21's boundary.
3. Political scale — who's actually in charge, at what headcount (ASOIAF / Black Company scale logic)?
4. Tradeable knowledge (pillar 8 / D5.10) — what does this faction sell that's a *fact*, not a good?
5. Visual anchor — which existing reference (ukiyo-e, Naruto aesthetic, paper-doll) already covers this without inventing a new one?

Any beat that can't find a home in an existing owned row is a genuine gap — handle it the way ukiyo-e was handled: flag it, don't just take the territory.
