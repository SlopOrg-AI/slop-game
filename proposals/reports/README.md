# proposals/reports — one report per prompted execution-agent session

Proposed 2026-09-20 (`proposals/2026-09-20-session-reports.md`, rides with D5.41). Owner: *"other cc leads should output reports as session artifacts upon prompting, these should be provided to tech and respective lead. that should be what tech is reviewing rather than larger output from other cc agents."*

`YYYY-MM-DD-<agent>-<topic>.md`, filed by the agent that did the work, in its own commit, under its own name. Copy `_TEMPLATE.md`.

**Two readers.** Tech reads the custody half — paths, commits, anything outside your lane, anything left uncommitted — and reviews *that* instead of your output. Your lead reads the substance half and judges the work.

**A report states; it never rules.** No D-numbers (AGENTS §1.4). No board rows — hand them to Tech (D5.38). No edits to another lead's brief (D5.27). Never deleted; a correction is a new report citing the old one.
