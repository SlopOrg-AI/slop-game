One line per decision, chronological, never delete — supersede with a later entry. Later entry wins; docs get corrected to match. Owner decisions only; agent proposals go to `proposals/` until logged here.

**D1–D4 (v1, 2026-09-19/20):** still to be compressed into this table — **Systems' judgement, not Tech's**; nobody has ruled which of them survive D5.25–D5.40. Until then the record is `sources/v1/docs/combat-scene-decisions.md`, **rescued into this repo 2026-09-20** (D5.40) from the frozen PC workspace, where it was cited by number from the system docs and reachable from one disk only.

**Tag** — the suffix on every D-number names the leads with an interest, so an agent finds its rows by matching instead of reading (D5.43-P):

| Letter | Interested party | Reads it because |
|---|---|---|
| **S** | Systems | rules, ontology, vocabulary, standing design guidance |
| **A** | Art / Direction | presentation grammar, camera, UI, world look |
| **C** | Content | instances — abilities, characters, factions |
| **E** | Engine / Tech | something must be built, validated or tooled |
| **P** | Process | roles, repo, milestones, how agents work |

A row may carry more than one letter; most carry one. **Match on the numeric part** — `D5.30` and `D5.30-ES` are the same row, and a tag may be corrected in place without renumbering. **This log is not read end to end**; it is consulted by tag or by D-number when two docs disagree, when an agent is about to change something a D-number settled, or on ratification (D5.43-P cl.6).
