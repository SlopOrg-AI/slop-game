**D1–D4 (v1, 2026-09-19/20):** still to be compressed into this table — **Systems' judgement, not Tech's**; nobody has ruled which of them survive D5.25–D5.40. Until then the record is `sources/v1/docs/combat-scene-decisions.md`, **rescued into this repo 2026-09-20** (D5.40) from the frozen PC workspace, where it was cited by number from the system docs and reachable from one disk only.

**`Acts on it`** — who has to do something about this row, so nobody reads 30 entries looking for their three:

| Value | Meaning | If it's wrong |
|---|---|---|
| **Engine** | Code or data implements it; there is a behaviour or a number | The game plays differently — catchable in play |
| **Vocabulary** | Fixes what a term *means*; every doc, JSON file and lead must use it that way | Two docs mean different things by one word and nobody notices |
| **Designers** | A standing instruction to whoever designs next — usually a *don't*. Nothing implements it | Nothing now; it reappears in the schema months later |
| **Content** | One instance — an ability, a character, a faction | One thing is wrong; fix the JSON |
| **Art** / **Production** | Presentation grammar; process, tooling, milestones | — |

A row may carry two. A row that would carry three is really two rows — see D5.9, which bundled a vocabulary statement with an undecided rule and had to be unpicked by D5.25 fifteen entries later.
